# EDHACK

אתר האקתון להוראת המדעים המדויקים של הפקולטה למדעים מדויקים באוניברסיטת תל אביב.

האתר בנוי מקובץ `index.html` ומלוגו הפקולטה בנתיב `assets/img/faculty-he-light.png`, ללא תהליך בנייה או תלויות להתקנה.

## עדכון טופס ההרשמה

בראש `index.html`, באובייקט `window.EDHACK`, מעדכנים את `registrationUrl` בקישור המענה של Google Forms, ולא בקישור העריכה. הכתובת מוגדרת במקום אחד בלבד ומעדכנת אוטומטית את כל שלושת כפתורי ההרשמה ואת הסטטוס באתר.

כאשר הערך ריק, מוצג ״ההרשמה טרם נפתחה״ וכפתורי פרטי ההרשמה מובילים למקטע ההרשמה בעמוד.

## עדכון הפרטים המסומנים TB

באותו אובייקט, תחת `details`, מחליפים את הערך `"TB"` בשדה `value` של הפרט הרלוונטי. העדכון יופיע בכל המקומות המתאימים בעמוד. משאירים `TB` עבור פרטים שטרם נקבעו.

## תצוגה מקומית

פותחים את `index.html` בדפדפן, או מריצים בתיקיית האתר:

```sh
python3 -m http.server 8000
```

לאחר מכן פותחים את `http://localhost:8000`.
